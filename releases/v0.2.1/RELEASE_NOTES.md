## TabWheel v0.2.1

This patch release completes TabWheel's first fully packaged open-source distribution.

### Highlights

- Scroll over the native top tab strip to switch tabs in Chrome, Edge, Brave, Vivaldi, and Opera.
- Automatically removes the mouse hook while games or other applications are in the foreground.
- Includes distinct enabled and disabled tray icons.
- Keeps the 50 ms tab-strip detection cache and 120 ms switch throttle from v0.2.0.
- Adds the MIT License to both the source tree and the downloadable ZIP.
- Adds English and Simplified Chinese documentation, automated builds, release verification, and community templates.

### Download

`TabWheel-Windows-v0.2.1.zip` is the recommended package. It contains the executable, both README files, the MIT License, icons, and the README demonstration image.

Existing `Enabled` and `ReverseDirection` settings remain compatible with v0.2.0.

> The executable is not code-signed yet. Windows SmartScreen may show an "Unknown publisher" warning. Verify the supplied SHA-256 checksums or build directly from source if required.
