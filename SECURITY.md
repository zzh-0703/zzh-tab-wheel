# Security Policy

## Supported versions

Security fixes are provided for the latest published `0.2.x` release. Older builds may be asked to upgrade before a report is investigated.

## Reporting a vulnerability

Do not open a public issue for a security vulnerability.

Use GitHub's **Security → Report a vulnerability** form to send the details privately to the maintainer:

https://github.com/zzh-0703/zzh-tab-wheel/security/advisories/new

Include the affected TabWheel version, Windows version, browser and version, reproduction steps, expected impact, and any suggested mitigation. Please allow the maintainer reasonable time to investigate before disclosing the issue publicly.

TabWheel listens for mouse-wheel events but is not designed to collect keyboard input, page content, tab titles, URLs, or personal data. Reports showing behavior outside these boundaries are especially important.
